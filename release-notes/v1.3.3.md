Symbols, the way you'd type them.

## What's new

- **Money and percent.** "five dollars" types `$5`, "three fifty dollars" types `$3.50`, "five dollars and fifty cents" types `$5.50`, and "twelve point five percent" types `12.5%`.
- **File names.** "readme dot md" types `readme.md`, "index dot test dot ts" types `index.test.ts`, and "dot env" types `.env`. The name keeps its case, so "README dot md" stays `README.md`.
- **Dev symbols.** Say "underscore" (`my_file`), "backslash", "asterisk", or "tilde". Symbols that are also everyday words need a second word so normal speech is left alone: "plus sign", "equals sign", "percent sign", "dollar sign", "hash sign", "pipe symbol".

## Install

1. Download Goji.dmg below (or Goji-with-model.dmg if your Mac can't download the model at first run).
2. Open it and drag Goji to the Applications folder.
3. Launch Goji. Grant Microphone (prompt) and Accessibility (System Settings > Privacy & Security > Accessibility).

Requires macOS 14 or later. Apple Silicon recommended.
