The mic no longer randomly dies until you reboot.

## What's fixed

- Dictation could stop picking up any microphone, and neither relaunching Goji nor picking a different mic brought it back; only a reboot did. Cause: the old recorder always woke the system default input (usually Bluetooth headphones) before switching to your chosen mic, so every dictation poked the Bluetooth mic even when Goji was set to the built-in one. Once macOS's Bluetooth audio stack wedged, every mic went silent. Goji now opens the mic you chose directly and never touches the default device.
- If a held recording produces no audio at all, the menu bar now says so ("Mic delivered no audio") instead of silently doing nothing.

## Install

1. Download Goji.dmg below.
2. Open it and drag Goji to the Applications folder.
3. Launch Goji. Grant Microphone (prompt) and Accessibility (System Settings > Privacy & Security > Accessibility).

Requires macOS 14 or later. Apple Silicon recommended.
